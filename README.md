## ポート開放・占有IPについて

- ポート開放・ポート転送等の設定や変更には、管理者への事前申請と許可が必要です。一律の利用制限はありませんが、他の利用者やネットワークに支障を及ぼさないよう、常識的な範囲で利用してください。
- 占有IPv4は、非商用利用であり、空きがある場合に割り当てを受けられます。商用利用には占有IPを割り当てません。
- 占有IPと共有IPの相互変更では、設定変更作業に伴うダウンタイムが発生する場合があります。

詳細は[利用規約 第5条の2](./terms.md#第5条の2ポート開放ポート転送および占有ip)を確認してください。

## 無償リセールについて

KVMで貸し出されたVMの一部を信頼できる友人に無償で提供する場合は、提供開始前に管理者へ申請し、許可を得る必要があります。エンドユーザーにも利用規約および特則が適用され、管理者への一次的な責任はリセール提供者が負います。

詳細は[無償リセールに関する特則](./resale.md)を確認してください。
